# 2026-09-11 工作日志

## 真机新发现 bug（飞腾平台）

### Bug A：循环休眠卡"系统休眠中"
- 根因：当前代码**无"休眠 N 秒后自动唤醒"机制**（无 rtcwake、无 systemd sleep hook）
- "40 秒倒计时"实际是"唤醒→下次休眠的间隔"，**不是"休眠时长"**
- 第一次休眠被外部源唤醒（BIOS 定时/手动/系统设置），第二次后外部源不再触发 → 永久卡死
- 修复：cycle_controller 在 suspend/hibernate 前用 rtcwake -m mem -s N 一次性发起"休眠 N 秒"

### Bug B：suspend 期间断电未识别为非法关机
- 根因：suspend() 调 markCleanShutdown() 删 flag + suspend 不断电 boot_id 不变
- suspend 期间断电 → boot_id 变 + flag 删 → 看起来像"软件从未启动过" → 漏判
- 修复：suspend 写 marker（带时间戳），启动时比 marker 时间 vs boot 时间判定"被断电"还是"正常唤醒"
